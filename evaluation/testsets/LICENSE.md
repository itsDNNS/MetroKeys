# Licence of the evaluation test data

The files in `evaluation/testsets/` and `evaluation/lexicon/` are generated by `tools/build_evaluation.py` (spec
05c) for the dictionary evaluation of MetroKeys. They are repository files for the tests and are never packaged in the
app. They contain material of these sources (05c §2.4):

- **Words and frequencies**: wordfreq © Robyn Speer, CC BY-SA 4.0 (https://github.com/rspeer/wordfreq), which contains
  data from Wikipedia, OPUS OpenSubtitles 2018, SUBTLEX (Brysbaert et al.), Google Books Ngrams and the further sources
  named in its README; FrequencyWords © Hermit Dave (OpenSubtitles 2018), CC BY-SA 4.0; spellings from Wiktionary
  (de, en, es, pt, it, fr.wiktionary.org), authors see page histories, CC BY-SA 4.0; SCOWL © Kevin Atkinson and
  others (wordlist.aspell.net), see the SCOWL notice (`engine/src/main/resources/app/metrokeys/engine/dict/SCOWL-Copyright.txt`);
  the spelling dictionaries igerman98 with the frami additions (GPL 2 or 3), RLA-ES (GPL 3 or later), VERO
  (LGPL 3), Dizionario italiano (GPL 3) and Dicollecte (MPL 2.0), used for membership only.
- **Sentences**: Tatoeba (tatoeba.org), authors see the sentence pages (the sentence id is given in the `sentenceId`
  column as `tatoeba:<id>`), CC BY 2.0 FR (some sentences CC0); Mozilla Common Voice sentence collection
  (`cv:<file>:<line>`), CC0 1.0.
- **Real misspellings** (set R): Wikipedia, CC BY-SA 4.0, authors see the page histories:
  en.wikipedia.org "Wikipedia:Lists of common misspellings/For machines" (revision 1199637275),
  es.wikipedia.org "Wikipedia:Corrector ortográfico/Listado" (175669831),
  fr.wikipedia.org "Wikipédia:Liste de fautes d'orthographe courantes" (229968367),
  pt.wikipedia.org "Wikipédia:Lista de erros comuns/Máquinas" (62178396),
  de.wikipedia.org "Wikipedia:Häufige Falschschreibungen" (260871597).

Modified: words selected, ranked and altered by generated typing errors; sentences cut after the evaluated word.
The test data as a whole is distributed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
